# H-DO — محمّل فيديو وصوت (يوتيوب، فيسبوك، +1000 موقع)

تطبيق مفتوح المصدر مبني على **yt-dlp** مع واجهة عربية/إنجليزية حديثة. يعمل على **ويندوز / لينكس / ماك / أندرويد (Termux)** ويُستخدم من أي متصفح، ويمكن تثبيته كتطبيق على شاشة الهاتف (PWA).

## المميزات
- تحميل فيديو أو صوت فقط من يوتيوب وفيسبوك وإنستغرام وتيك توك وتويتر وغيرها (كل ما يدعمه yt-dlp).
- اختيار الجودة (حتى 4K) والصيغة (mp4/mkv/webm) والصوت (mp3/m4a/opus/flac/wav).
- **تحميل سريع**: الصق رابطاً أو عدة روابط (سطر لكل رابط) وابدأ فوراً بالإعدادات الافتراضية.
- قوائم التشغيل: تحميل كاملة أو عناصر مختارة، كل عنصر مهمة مستقلة في مجلد باسم القائمة.
- قائمة انتظار مع تحميلات متزامنة (1–6)، نسبة وسرعة ووقت متبقٍ، إلغاء وإعادة محاولة (يستكمل من حيث توقف).
- **استئناف تلقائي** بعد إغلاق البرنامج أو انقطاع الكهرباء (القائمة محفوظة في قاعدة بيانات).
- كشف التكرار قبل إعادة تحميل نفس الرابط.
- دمج الغلاف والبيانات والفصول داخل الملف، وترجمة (ar,en…) مدمجة، وتخطي الإعلانات داخل فيديوهات يوتيوب (SponsorBlock).
- ملف **cookies.txt** للفيديوهات الخاصة في فيسبوك/يوتيوب، وبروكسي، وحد للسرعة.
- زر **حفظ** يرسل الملف لجهازك من المتصفح — مفيد حين يعمل H-DO على حاسوب/خادم وتتصفح من الهاتف.
- **استقبال الروابط من تطبيقات أخرى**: بعد تثبيت H-DO كتطبيق (PWA) يظهر ضمن قائمة "مشاركة".
- تحديث yt-dlp من الإعدادات بضغطة واحدة (مهم لأن المواقع تتغير باستمرار).
- حماية اختيارية بكلمة مرور عند فتحه على الشبكة.

## التشغيل
المتطلبات: Python 3.10+ ، و[ffmpeg](https://ffmpeg.org) (مطلوب للدمج وتحويل MP3 ودمج الغلاف؛ بدونه يعمل بوضع الملف الواحد).

```bash
./run.sh          # لينكس / ماك / Termux      (ويندوز: run.bat)
# ثم افتح http://127.0.0.1:8080
```

**على أندرويد (Termux):**
```bash
pkg install python ffmpeg git && termux-setup-storage
git clone <مستودعك> && cd hdo && ./run.sh
```
افتح `http://127.0.0.1:8080` في Chrome ← ⋮ ← "تثبيت التطبيق". التحميلات تُحفظ في `Download/H-DO`.

**Docker:**
```bash
docker build -t hdo . && docker run -p 8080:8080 -e HDO_PASSWORD=كلمة_سر -v hdo-data:/data -v $PWD/dl:/root/Downloads hdo
```

### متغيرات البيئة
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `HDO_HOST` | `127.0.0.1` | ضع `0.0.0.0` للوصول من أجهزة الشبكة |
| `HDO_PORT` | `8080` | المنفذ |
| `HDO_PASSWORD` | — | كلمة مرور (يُنصح بها دائماً عند الفتح على الشبكة) |
| `HDO_DATA` | `~/.hdo` | الإعدادات وقاعدة البيانات والكوكيز |

## فيسبوك والفيديوهات الخاصة
الفيديوهات العامة تعمل مباشرة. للخاصة أو المقيّدة: صدّر الكوكيز بصيغة Netscape من متصفحك (إضافة "Get cookies.txt LOCALLY") وارفعها من ⚙ الإعدادات. يطلب يوتيوب أحياناً تسجيل الدخول لإثبات أنك لست روبوتاً، والحل نفسه.
