# H-DO for Android (v1.6.3)

تطبيق أصلي بـ Kotlin وJetpack Compose لتحميل الفيديو والصوت. المؤسس: Hamdy Mansour. الترخيص: GPL-3.0.

## المحرك
- **NewPipe Extractor** هو المسار السريع ليوتيوب وساوند كلاود (بدون Python).
- **yt-dlp + Python + ffmpeg** (عبر youtubedl-android) احتياطي للمواقع الأخرى ولو فشل NewPipe. يتحمّل عند الحاجة فقط.
- يفضّل الاستريمات avc1+mp4a لأن بعض الأجهزة لا تفك AV1/VP9 بالعتاد.

## الصفحات
- **الرئيسية**: بحث بالاسم (يوتيوب / يوتيوب ميوزك / ساوند كلاود) أو لصق رابط، معاينة فيديو بجودة قابلة للتغيير، وشريط الحافظة (فيه زر X للإغلاق).
- **التنزيلات**: الجارية والمتوقفة والفاشلة والمكتملة، مع فلاتر وبحث وفرز ومشغّل مدمج.
- **الإعدادات**: المظهر، الرئيسية والبحث، التحميل (ومنها جودة المعاينة)، الشبكة، الإشعارات، التخزين، الأمان (قفل التطبيق، مجلد خاص)، **النسخ الاحتياطي** (للإعدادات فقط، وليس قائمة التحميلات).
- **حول**: الاسم والإصدار، فحص التحديث، رابط GitHub، وسجل التشخيص للمطور.

## ميزات التحميل
- فيديو أو صوت، حاويات وجودات مختلفة، ترجمات، تضمين البيانات، تخطي إعلانات SponsorBlock، قص جزء من الفيديو، جدولة التنزيل، تنزيل قوائم التشغيل.
- استئناف وتجزئة التنزيل (RangeDl) وإعادة المحاولة التلقائية.
- المشاركة من أي تطبيق إلى H-DO، وبلاطة الإعدادات السريعة «الصق وحمّل».

## ملاحظات
- الكوكيز: واجهة الاستيراد مخفية (`Config.SHOW_COOKIES`)، لكن أي ملف cookies.txt مستورد سابقاً يظل مستخدماً.
- يتطلب أندرويد 10 أو أحدث (minSdk 29). يحفظ في `Download/H-DO/` عبر MediaStore، أو في مجلد خاص مخفي عن المعرض لو فعّلت الخيار.
- فحص التحديث يقرأ آخر إصدار من `Config.UPDATE_REPO` (`Hamddyy/H-DO`).

## البناء والإصدار
- **الإصدار الرسمي (موقّع)**: ارفع المشروع إلى `main`، ثم GitHub ← Actions ← *Release signed APK* ← Run workflow، واكتب رقم الإصدار بدون v (يطابق `versionName` في `app/build.gradle.kts`). الـ workflow يبني APK لـ arm64 وarmeabi-v7a، ويوقّعهم بالمفتاح المخزن في GitHub Secrets، وينشرهم في Releases.
- الأسرار المطلوبة: `HDO_KEYSTORE_B64` و`HDO_KEYSTORE_PASSWORD` و`HDO_KEY_ALIAS` و`HDO_KEY_PASSWORD` (شرح بالعربي في `SIGNING-SECRETS-AR.md`).
- **محلياً**: `./gradlew assembleRelease` (JDK 17). بدون متغيرات التوقيع يخرج APK غير موقّع.
- لا ترفع ملف المفتاح (keystore) إلى المستودع أبداً، ولا تضعه في Downloads العامة.
